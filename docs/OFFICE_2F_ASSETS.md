좋습니다. 2층은 **한 번에 전부 만들기보다, 조립 가능한 공통 에셋부터 만든 뒤 팀별 전용 에셋을 추가하는 순서**가 가장 효율적입니다.

# 실제 이미지 생성 순서

제가 이미지로 제작한다면 아래 순서가 좋습니다.

### 1차 생성: 바닥 타일
먼저 이것만 만듭니다.

- 밝은 오피스 바닥
- 우드 바닥
- 서버실 바닥
- 복도 바닥
- 코너/테두리용 타일

전부 **투명배경 + 동일 시점 + 동일 크기 규칙**으로 갑니다.

### 2차 생성: 벽/유리벽
그다음 맵 뼈대를 만듭니다.

- 일반 벽 가로/세로
- 코너 벽
- 유리벽 가로/세로
- 유리벽 코너
- 유리문
- 낮은 파티션
- 높은 파티션

### 3차 생성: 업무용 기본 가구
이게 핵심입니다.

- 1인 책상
- 2인 책상
- 4인 책상
- 의자 4방향
- 모니터
- 듀얼 모니터
- 노트북
- 캐비닛
- 책장

### 4차 생성: 장식물
- 대형 화분
- 중형 화분
- 소형 화분
- 스탠드 조명
- 벽 조명
- 포스터 보드
- 휴지통

### 5차 생성: 인사팀
- 인사팀 사인
- 인사팀용 책상 조합
- 서류 캐비닛
- 문서 보관장
- 인사 상담 테이블

### 6차 생성: 개발팀
- 개발팀 사인
- 개발자 책상
- 듀얼/트리플 모니터
- 장비 선반
- 기술 보드
- 개발 장비 디테일

### 7차 생성: 마케팅팀
- 마케팅팀 사인
- 일반 업무 책상
- 캠페인 보드
- 브레인스토밍 보드
- 샘플 진열대

### 8차 생성: 서버실
이건 별도 세트로 빼는 게 좋습니다.

- 서버랙 A
- 서버랙 B
- 네트워크 랙
- 서버 콘솔
- 경고등

- 케이블 바닥

### 9차 생성: 공용 공간
- 폰부스
- 복합기
- 업무 라운지
- 소파
- 테이블
- 휴게공간

### 10차 생성: 안내/브랜딩
마지막에 넣습니다.

- 2F

- 마케팅팀

# 실서비스용 규칙

이미지를 만들 때 아래 규칙을 처음부터 고정해야 나중에 개발이 편합니다.

- **배경은 항상 투명 PNG**
- **같은 카메라 각도**
- **같은 광원 방향**
- **같은 픽셀 밀도**
- **같은 비율**
- **바닥 기준선 통일**
- **오브젝트 그림자 방향 통일**
- **가구 크기 비율 통일**

예를 들어 책상은 전부 같은 기준으로:

```text
1칸 = 32px
또는
1칸 = 64px
```

처럼 잡는 게 좋습니다.

개인적으로는 지금처럼 디테일이 많은 스타일이면 **64px 타일 기준**이 더 잘 맞습니다.

# 가장 좋은 실제 작업 순서

첫 제작 묶음은 이렇게 가는 걸 추천합니다.

**1. 바닥**
**2. 벽**
**3. 유리벽**
**4. 파티션**
**5. 책상**
**6. 의자**
**7. 컴퓨터**
**8. 화분**

여기까지 만든 뒤 Tiled에서 2층 맵을 먼저 조립해보면 됩니다.

그 다음 부족한 걸 확인하고 서버실, 폰부스, 복합기 등을 추가하는 방식이 가장 효율적입니다.

다음 단계로는 **2층 1차 에셋 세트부터 실제 이미지로 제작**하면 됩니다. 시작은 `바닥 + 벽 + 유리벽 + 파티션` 묶음이 가장 좋습니다.
