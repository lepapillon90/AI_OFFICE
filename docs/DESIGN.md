# AI 오피스 — Phase 1 웹 데모

## 목표

브라우저에서 실행되는 픽셀 가상 오피스의 첫 동작 데모를 만든다. 사용자는 한 명의 캐릭터를 WASD 또는 방향키로 움직이고, 카메라는 캐릭터를 따라가며, 벽과 책상을 통과할 수 없어야 한다.

## 범위

- Flutter Web 앱과 Flame 게임 화면
- 제공된 바닥·벽 PNG 에셋의 재사용
- 64px 화면 그리드에 맞춘 한 화면짜리 오피스 맵
- 회의실, 업무 좌석, 휴게 구역
- 새 2D 픽셀 에셋: 4방향 걷기 캐릭터 1명, 책상, 의자, 컴퓨터, 화분, 소파, 커피머신
- 키보드 이동, 카메라 추적, 벽·책상 충돌

## 제외 범위

로그인, Supabase, 멀티플레이, 채팅, 오브젝트 사용 UI, AI NPC와 AI 서버 연결은 이후 단계에서 추가한다.

## 기술 선택

- 앱: Flutter Web
- 게임 화면: Flame
- 맵: 우선 코드 기반의 고정 레이아웃; 이후 Tiled 맵으로 전환 가능
- 자산: `assets/images/tiles/` 아래의 제공·생성 PNG

## 완료 기준

웹 앱에서 캐릭터가 바닥 위를 이동하고 카메라가 추적하며, 벽과 책상 충돌로 이동이 막히는 장면을 직접 확인한다.
