# AI 오피스 전체 로드맵

## 제품 목표

사람과 AI 직원이 같은 픽셀 오피스 공간에서 일하고, 대화하고, 업무 상태와 결과를 확인하는 웹 기반 가상 오피스입니다.

## Phase 1 — 가상 오피스 기본 이동 ✅

- Flutter Web + Flame 오피스 맵
- 플레이어 캐릭터, 카메라 추적, WASD·방향키 이동
- 벽·책상 충돌
- 바닥·벽·가구 픽셀 에셋

완료 기준: 브라우저에서 캐릭터가 오피스를 자유롭게 이동하고 장애물을 통과하지 않습니다.

## Phase 2 — 오브젝트 상호작용 ✅

- 컴퓨터 가까이에서 `[E] 컴퓨터 사용` 안내
- E 키로 개발 AI 컴퓨터 팝업 열기
- 팝업: 개발 AI, 대기 중, 업무 지시, 대화하기, 작업 확인
- ESC·닫기 버튼으로 게임으로 돌아가기

완료 기준: 컴퓨터를 사용하고 닫은 뒤 다시 캐릭터를 이동할 수 있습니다. 실제 AI 연결은 하지 않습니다.

## Phase 3 — NPC와 AI 직원 표현 🚧

- AI 직원 NPC와 자리 배정
- 대기·작업 중·회의 중·오류 상태 표시
- NPC 머리 위 상태 문구와 상태 색상
- 컴퓨터와 AI 직원 연결

완료 기준: 각 컴퓨터가 한 AI 직원과 연결되고 현재 상태가 맵에서 보입니다.

## Phase 4 — 회사 데이터와 계정

- Supabase Auth 로그인
- 회사·공간·직원 데이터 모델
- 직원 역할과 AI 제공자 설정 저장
- 오피스 레이아웃 저장

완료 기준: 로그인한 사용자가 자신의 회사와 직원 구성을 저장·복원합니다.

## Phase 5 — 멀티플레이와 채팅

- Supabase Realtime으로 사용자 위치 공유
- 같은 공간의 다른 사용자 표시
- 공간 채팅과 직원별 대화 기록
- 초대와 권한 기본 모델

완료 기준: 두 사용자가 같은 회사 오피스에서 서로의 이동과 채팅을 실시간으로 확인합니다.

## Phase 6 — AI 직원 업무 실행

- AI 제공자 연결(OpenAI 등)
- 직원별 역할·시스템 지시·업무 컨텍스트
- 업무 지시, 진행 상태, 결과 기록
- 오류·재시도·사용량 기록

완료 기준: 사용자가 컴퓨터 팝업에서 업무를 지시하고 AI 직원의 결과를 확인합니다.

## Phase 7 — 협업 기능과 운영

- 회의실·회의 진행 UI
- 프로젝트·업무 보드 연결
- 알림과 활동 기록
- 관리자 화면, 감사 기록, 권한 강화
- 성능·보안·배포 운영 점검

완료 기준: 팀이 가상 오피스를 실제 협업 공간으로 안정적으로 사용할 수 있습니다.

## 원칙

- 한 단계의 완료 기준을 검증한 뒤 다음 단계로 이동합니다.
- AI·실시간·인증 기능은 UI와 상태 모델이 안정된 뒤 연결합니다.
- 사용자 데이터와 AI API 키는 클라이언트에 저장하지 않습니다.
