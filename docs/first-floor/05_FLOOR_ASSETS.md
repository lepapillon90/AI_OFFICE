# 1층 5단계 — 바닥 에셋

## 목적

1층 전체 공간의 비율과 구역 경계를 확인할 수 있도록 바닥 에셋을 먼저 확정한다. 바닥은 벽·가구·NPC보다 먼저 배치하며, 이 단계에서는 맵 기능이나 충돌을 구현하지 않는다.

## 확정 규격

| 항목 | 기준 |
| --- | --- |
| 타일 캔버스 | 32×32px |
| 지도 규격 | 48×32 타일 / 1536×1024px |
| 시점 | 아이소메트릭 다이아몬드형 |
| 배경 | 투명 PNG |

## 공식 스타일 원본

`assets/source/office_1f/floor-style-reference.png`

이 원본의 네 타일을 바닥 감성의 기준으로 삼는다. 파일명 글자는 게임에 사용하지 않는다.

## 제작 규칙

- 타일 윗면은 다이아몬드형 아이소메트릭 형태를 유지한다.
- 얇은 입체 옆면과 자연스러운 그림자를 둔다.
- 모든 타일은 같은 기울기·외곽선 두께·하단 기준점을 사용한다.
- 바닥의 텍스처는 반복해도 피로하지 않도록 단순하게 유지한다.
- 타일 이름, 글자, 배경판은 런타임 파일에 포함하지 않는다.

## 상태

이전 테스트용 바닥 타일은 폐기했다. 현재는 사용자 원본을 기준으로 실제 32×32 런타임 PNG를 새로 분리·제작하기 전 단계다. 다음 작업은 기본 타일 4종의 독립 PNG 제작이며, 그 다음에 경계·모서리·전환 타일을 추가한다.
