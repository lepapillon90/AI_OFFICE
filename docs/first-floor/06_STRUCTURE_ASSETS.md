# 1층 6단계 — 벽과 구조물

## 목표

1층의 건물 골격을 구성할 일반 벽, 코너 벽, 유리벽, 유리문, 엘리베이터 프레임, 계단, 출입구의 시각 방향을 확정한다. 이 단계에는 맵 배치와 게임 기능이 포함되지 않는다.

## 확정 감성

- 따뜻한 크림색 하단 몰딩과 샴페인 골드 조명
- 깊은 네이비 구조 프레임
- 밝은 하늘색 유리와 부드러운 반사광
- 바닥 스타일 원본과 어울리는 정돈된 2.5D 아이소메트릭 형태
- 과도하게 딱딱한 픽셀 외곽선 대신, 부드럽고 고급스러운 게임 에셋 질감

## 구조물 구성

| 구조물 | 위치·용도 |
| --- | --- |
| 일반 벽 | 전체 실내 구역의 기본 경계 |
| 코너 벽 | 리셉션·카페·매점 구역의 방향 전환 |
| 유리벽 | 카페·로비·출입구의 개방감 |
| 유리문 | 내부 구역 출입 |
| 엘리베이터 프레임 | 상단 중앙의 층 이동 |
| 계단 | 우측 상단의 층 이동 |
| 출입구 | 하단 중앙의 외부 입장 |

## 사용 구역별 벽 구성

벽은 공통 프레임·조명 언어를 공유하되, 공간의 목적에 따라 면 재질과 개방 정도를 다르게 구성한다.

| 구역 | 벽 구성 | 필요한 변형 |
| --- | --- | --- |
| A. 외부 입구 | 낮은 크림 석재 경계, 넓은 유리 파사드, 출입구 프레임 | 외벽 직선·코너, 유리 파사드, 출입구 좌우 기둥, 화단 경계 |
| B. 중앙 로비 | 시야를 막지 않는 낮은 파티션과 유리 면 위주 | 낮은 벽, 짧은 유리벽, 화단 결합 경계 |
| C. 리셉션 | 따뜻한 크림 패널 벽과 안내 조명 | 일반 벽, 코너 벽, 리셉션 뒤 배경 벽, 벽 조명 변형 |
| D. 엘리베이터 | 가장 견고한 네이비·크림 엘리베이터 코어 | 엘리베이터 좌우 프레임, 상단 헤더, 안내판 결합 벽 |
| E. AI CAFE | 외부와 보이도록 유리벽을 많이 쓰고, 카운터 뒤는 크림 패널 벽 | 긴 유리벽, 짧은 유리 칸막이, 카페 백바 벽, 코너 벽 |
| F. AI STORE | 상품 진열을 받는 단단한 후면 벽과 일부 유리 전면 | 선반 결합 벽, 진열 후면 벽, 유리 전면, 코너 벽 |
| G. 라운지 | 소프트한 반높이 파티션과 유리벽으로 열린 휴식 공간 | 낮은 파티션, 화분 결합 파티션, 짧은 유리벽 |
| H. 계단 | 안전을 위한 폐쇄형 측벽과 난간 | 계단 측벽, 난간 결합 벽, 계단 상단·하단 코너 |

### 공통 원칙

- 모든 구역은 네이비 프레임, 크림 하단 몰딩, 따뜻한 골드 조명을 공통 언어로 사용한다.
- 벽의 높이 차이는 시야와 이동성을 위한 것이며, 충돌 영역은 실제 통과 불가 면만 적용한다.
- 같은 구역 안에서도 직선·끝·내부 코너·외부 코너·문 결합형을 별도 에셋으로 제작한다.
