# 1층 6단계 — 벽과 구조물

## 목적

일반 벽부터 출입구까지의 구조물을 먼저 정의해 1층의 건물 골격을 만든다. 맵 배치, 충돌, 상호작용은 아직 추가하지 않는다.

## 구조물 목록

| 구조물 | 용도 |
| --- | --- |
| 일반 벽 | 실내·외 구역의 기본 경계 |
| 코너 벽 | 벽 방향 전환 |
| 유리벽 | 카페·로비·출입구의 개방감 |
| 유리문 | 구역 출입 |
| 엘리베이터 프레임 | 상단 중앙의 층 이동 시설 |
| 계단 | 우측 상단의 층 이동 시설 |
| 출입구 | 하단 중앙의 외부 입장 시설 |

## 시각 규칙

- 바닥 공식 원본과 같은 선명한 픽셀 표현을 유지한다.
- 구조물 외곽은 짙은 네이비 프레임으로 통일한다.
- 벽면은 따뜻한 크림·베이지, 유리면은 밝은 청색, 금속·프레임은 네이비 계열을 사용한다.
- 모든 구조물은 독립 PNG로 분리 가능해야 하며, 그림 바깥에 방 배경을 포함하지 않는다.
