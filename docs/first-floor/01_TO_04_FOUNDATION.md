# 1층 재제작 — 1~4단계 기준서

## 1단계: 기준 이미지 확정

1층은 따뜻하고 밝은 아이소메트릭 RPG형 AI Office 로비를 기준으로 한다. 화면 전체는 입구에서 중앙 로비를 지나 리셉션·엘리베이터로 이어지는 한눈에 읽히는 구조여야 한다.

확정한 위치는 다음과 같다.

- 하단 중앙: 외부 입구와 유리문
- 중앙: 큰 나무가 있는 중앙 로비
- 상단 중앙: 리셉션과 엘리베이터
- 좌측: AI CAFE
- 우측: AI STORE
- 우측 하단: 라운지
- 우측 상단: 계단

이 단계에서는 게임 코드와 실제 맵 배치를 만들지 않는다.

## 2단계: 맵 규격 확정

| 항목 | 확정값 |
| --- | --- |
| 타일 크기 | 32×32px |
| 맵 크기 | 48×32 타일 |
| 전체 작업 크기 | 1536×1024px |
| 시점 | 아이소메트릭 RPG |

모든 에셋은 32px 그리드를 기준으로 만들고, 큰 오브젝트는 여러 타일을 차지한다.

## 3단계: 구역과 동선 확정

| 코드 | 구역 | 기본 위치 |
| --- | --- | --- |
| A | 외부 입구 | 하단 |
| B | 중앙 로비 | 중앙 |
| C | 리셉션 | 상단 중앙 |
| D | 엘리베이터 | 상단 중앙 |
| E | AI CAFE | 좌측 |
| F | AI STORE | 우측 |
| G | 라운지 | 우측 하단 |
| H | 계단 | 우측 상단 |

동선 기준:

- 입구 → 중앙 로비 → 리셉션·엘리베이터: 3타일 이상
- 카페·매점·라운지 내부: 2타일 이상
- 벽·가구·화단 주변: 1타일 이상

장식보다 먼저 이 이동 폭을 확보한다.

### 제작 묶음과 순서

| 묶음 | 포함 에셋 | 목적 |
| --- | --- | --- |
| 4-A 바닥·구조물 | 바닥, 벽, 유리벽, 유리문 | 구역과 동선의 바탕 |
| 4-B 이동 시설 | 엘리베이터, 계단, 리셉션 데스크 | 상단 핵심 구조 |
| 4-C 상업·휴식 | 카페 카운터, 테이블, 의자, 소파, 선반, 냉장고 | 카페·매점·라운지 형태 |
| 4-D 랜드마크·장식 | 화분, 중앙 나무, 분수, 화단, 간판 | 공간의 기억점과 분위기 |

### 공통 제작 규칙

- 투명 배경 PNG를 사용한다.
- 각 에셋은 다른 곳에 다시 놓을 수 있도록 독립된 파일로 만든다.
- 작은 화분은 1×1, 테이블은 2×2, 카운터·선반은 4×2 이상, 중앙 나무는 5×5 이상 타일을 사용한다.
- 가구의 충돌 영역은 실제 그림 전체가 아니라 캐릭터가 발을 디딜 수 없는 하단 면적으로 따로 정의한다.
- 컵, 디저트, POS, 작은 장식은 1층 구조가 승인된 뒤 제작한다.

## 5단계: 바닥 에셋 제작

전체 맵의 비율과 구역 경계를 먼저 검토할 수 있도록 아래 네 종류의 바닥을 우선 제작한다.

| 바닥 | 사용 구역 | 색·질감 방향 |
| --- | --- | --- |
| 로비 타일 | 중앙 로비·리셉션 | 밝은 베이지 석재 |
| 카페 목재 바닥 | AI CAFE | 따뜻한 브라운 목재 |
| 라운지 카펫 | 라운지 | 차분한 오트밀 직조 질감 |
| 외부 석재 바닥 | 입구·외부 | 차가운 연회색 석재 |

기존 바닥 시안과 분리 타일은 디자인 방향 재검토를 위해 모두 폐기했다. 현재 바닥의 공식 시각 기준은 사용자가 제공한 `assets/source/office_1f/floor-style-reference.png`다. 네 타일의 형태·명암·입체 옆면은 이 원본을 따른다. 파일명 글자는 게임에 사용하지 않는다.

## 현재 진행

5단계 바닥의 스타일 기준은 확정됐지만, 실제 런타임용 32×32 PNG 분리는 아직 시작하지 않았다. 타일 분리와 맵 조립은 사용자의 다음 지시에 따라 진행한다.
