# 1층 재제작 — 1~4단계 기준서

## 1단계: 기준 이미지 확정

1층은 따뜻하고 밝은 아이소메트릭 RPG형 AI Office 로비를 기준으로 한다. 화면 전체는 입구에서 중앙 로비를 지나 리셉션·엘리베이터로 이어지는 한눈에 읽히는 구조여야 한다.

확정한 위치는 다음과 같다.

- 하단 중앙: 외부 입구와 유리문
- 중앙: 큰 나무가 있는 중앙 로비
- 상단 중앙: 리셉션과 엘리베이터
- 좌측: AI CAFE
- 우측: AI STORE
- 우측 하단: 라운지
- 우측 상단: 계단

이 단계에서는 게임 코드와 실제 맵 배치를 만들지 않는다.

## 2단계: 맵 규격 확정

| 항목 | 확정값 |
| --- | --- |
| 타일 크기 | 32×32px |
| 맵 크기 | 48×32 타일 |
| 전체 작업 크기 | 1536×1024px |
| 시점 | 아이소메트릭 RPG |

모든 에셋은 32px 그리드를 기준으로 만들고, 큰 오브젝트는 여러 타일을 차지한다.

## 3단계: 구역과 동선 확정

| 코드 | 구역 | 기본 위치 |
| --- | --- | --- |
| A | 외부 입구 | 하단 |
| B | 중앙 로비 | 중앙 |
| C | 리셉션 | 상단 중앙 |
| D | 엘리베이터 | 상단 중앙 |
| E | AI CAFE | 좌측 |
| F | AI STORE | 우측 |
| G | 라운지 | 우측 하단 |
| H | 계단 | 우측 상단 |

동선 기준:

- 입구 → 중앙 로비 → 리셉션·엘리베이터: 3타일 이상
- 카페·매점·라운지 내부: 2타일 이상
- 벽·가구·화단 주변: 1타일 이상

장식보다 먼저 이 이동 폭을 확보한다.

3. 유리벽
4. 유리문
5. 엘리베이터
6. 계단

9. 테이블

13. 냉장고
14. 화분
15. 중앙 나무
16. 분수
17. 화단
18. 간판

### 제작 묶음과 순서

| 묶음 | 포함 에셋 | 목적 |
| --- | --- | --- |
| 4-A 바닥·구조물 | 바닥, 벽, 유리벽, 유리문 | 구역과 동선의 바탕 |
| 4-B 이동 시설 | 엘리베이터, 계단, 리셉션 데스크 | 상단 핵심 구조 |
| 4-C 상업·휴식 | 카페 카운터, 테이블, 의자, 소파, 선반, 냉장고 | 카페·매점·라운지 형태 |
| 4-D 랜드마크·장식 | 화분, 중앙 나무, 분수, 화단, 간판 | 공간의 기억점과 분위기 |

### 공통 제작 규칙

- 투명 배경 PNG를 사용한다.
- 각 에셋은 다른 곳에 다시 놓을 수 있도록 독립된 파일로 만든다.
- 작은 화분은 1×1, 테이블은 2×2, 카운터·선반은 4×2 이상, 중앙 나무는 5×5 이상 타일을 사용한다.
- 가구의 충돌 영역은 실제 그림 전체가 아니라 캐릭터가 발을 디딜 수 없는 하단 면적으로 따로 정의한다.
- 컵, 디저트, POS, 작은 장식은 1층 구조가 승인된 뒤 제작한다.

## 5단계: 바닥 에셋 제작

전체 맵의 비율과 구역 경계를 먼저 검토할 수 있도록 아래 네 종류의 바닥을 우선 제작한다.

| 바닥 | 사용 구역 | 색·질감 방향 |
| --- | --- | --- |
| 로비 타일 | 중앙 로비·리셉션 | 밝은 베이지 석재 |
| 카페 목재 바닥 | AI CAFE | 따뜻한 브라운 목재 |
| 라운지 카펫 | 라운지 | 차분한 오트밀 직조 질감 |
| 외부 석재 바닥 | 입구·외부 | 차가운 연회색 석재 |

초기 평면 질감 시안은 [floor-atlas-v1.png](concepts/floor-atlas-v1.png)로 보관한다. 현재 기준은 참고 이미지처럼 다이아몬드형 윗면과 얇은 입체 옆면을 가진 [floor-atlas-v2-isometric.png](concepts/floor-atlas-v2-isometric.png)다. 승인 후 각 사분면을 32×32px 반복 타일 PNG로 분리하고, 바닥 경계·모서리·전환 타일을 추가한다.

## 현재 진행

5단계의 바닥 에셋 시안을 제작했다. 바닥 색·질감이 승인되기 전에는 맵 조립이나 게임 기능을 추가하지 않는다.
