# 1층 7단계 — 주요 가구

## 목적

1층의 공간 성격과 이동 동선을 결정하는 큰 가구를 먼저 제작·배치한다. 작은 장식물보다 큰 오브젝트를 우선해 카페, 매점, 라운지, 중앙 로비의 실제 사용 면적을 검토한다.

## 제작 우선순위

| 순서 | 오브젝트 | 사용 구역 | 역할 |
| --- | --- | --- | --- |
| 1 | 리셉션 데스크 | C. 리셉션 | 방문 안내와 상단 중앙의 기준점 |
| 2 | 카페 카운터 | E. AI CAFE | 카페 구역의 형태와 주문 동선 |
| 3 | AI STORE 진열대 | F. AI STORE | 매점의 진열·보행 동선 |
| 4 | 소파 | G. 라운지 | 휴식 구역의 외곽과 좌석 구성 |
| 5 | 테이블 | E. AI CAFE, G. 라운지 | 머무름·통행 폭 확인 |
| 6 | 의자 | E. AI CAFE, G. 라운지 | 실제 좌석 수와 이동 여유 확인 |
| 7 | 중앙 나무 | B. 중앙 로비 | 1층의 중심 랜드마크와 동선 분기점 |

## 크기 기준

모든 크기는 32px 타일을 기준으로 하며, 실제 에셋 크기는 제작 과정에서 정밀 조정한다.

| 오브젝트 | 최소 점유 타일 | 제작 기준 |
| --- | --- | --- |
| 리셉션 데스크 | 5×2 | 정면 안내 면과 직원 뒤 공간을 구분 |
| 카페 카운터 | 6×2 | 주문면·장비면·대기 공간을 고려 |
| AI STORE 진열대 | 3×2 | 여러 개를 조합해 통로를 만든다 |
| 소파 | 3×2 | 벽 또는 라운지 경계에 배치 |
| 테이블 | 2×2 | 의자와 함께 최소 4×4 영역 검토 |
| 의자 | 1×1 | 실제 의자 수만큼 이동 여유를 확보 |
| 중앙 나무 | 6×6 | 화단·벤치·안내 보드를 포함한 중앙 랜드마크 |

## 동선 규칙

- 중앙 나무·리셉션·엘리베이터를 잇는 주 동선은 3타일 이상 유지한다.
- 카페와 매점의 카운터 앞 대기 공간은 2타일 이상 유지한다.
- 테이블·소파·진열대 주변에는 플레이어와 NPC가 지나갈 1타일 이상을 남긴다.
- 큰 가구의 전체 그림이 아니라 실제 통행을 막는 하단 면만 충돌 영역으로 지정한다.

## 완료 기준

- 위 일곱 종류의 큰 오브젝트가 독립 PNG로 준비되어 있다.
- 각 오브젝트의 점유 타일과 충돌 하단 면을 기록한다.
- 48×32 지도 위에 큰 가구만 놓은 상태에서 모든 주·보조 동선이 확보된다.
- 이 완료 기준 전에는 소품·NPC·상호작용 기능을 추가하지 않는다.
