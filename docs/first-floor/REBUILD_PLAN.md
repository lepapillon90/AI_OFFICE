# 1층 재제작 설계서

## 1. 목적

1층을 단일 배경 이미지처럼 보이게 만드는 것이 아니라, 플레이어가 이동하고 NPC·시설과 상호작용할 수 있는 아이소메트릭 RPG 공간으로 다시 제작한다. 기준 레퍼런스는 사용자가 제공한 AI Office 1층 이미지이며, 이전 28×18 / 64px 구성과 그 생성 에셋은 사용하지 않는다.

## 2. 확정 규격

| 항목 | 기준 |
| --- | --- |
| 전체 지도 | 48×32 타일 |
| 타일 크기 | 32×32px |
| 작업 캔버스 | 1536×1024px |
| 시점 | 아이소메트릭(입체 사선) |
| 지도 제작 도구 | Tiled Map Editor |
| 런타임 | Flutter + Flame |

32px 단위는 카페 진열대·화분·사인처럼 작은 요소를 충분히 세밀하게 배치하기 위한 기준이다. 큰 가구는 여러 타일을 사용한다.

## 3. 보존·초기화 원칙

- 보존: `assets/1층`의 원본 에셋 시트와 사용자가 제공한 레퍼런스 이미지
- 초기화: 이전 1층 전용 생성 에셋, 28×18 배치, 바닥 배치, 전용 테스트, 이전 QA 이미지
- 현재 상태: 앱에는 빈 48×32 1층 기술 기반만 남아 있다. 새 에셋이나 배치를 임의로 재사용하지 않는다.

## 4. 1층 구역 설계

| 구역 | 위치 | 역할 | 핵심 오브젝트 |
| --- | --- | --- | --- |
| A. 입구·외부 조경 | 하단 | 스폰·첫인상 | 유리 출입구, 계단, 연못, 분수, 화단, 안내 사인 |
| B. 중앙 로비 | 중앙 | 주 동선·랜드마크 | 중앙 나무 화단, 안내 보드, 넓은 보행로 |
| C. 리셉션 | 상단 중앙 | 안내 NPC | 리셉션 데스크, 모니터, 대기 좌석 |
| D. 엘리베이터 | 상단 중앙 | 층 이동 | 엘리베이터 2대, 층 안내판, 호출 패널 |
| E. AI CAFE | 좌측 | 주문·좌석 | 카운터, 메뉴 보드, 커피 장비, 테이블·의자 |
| F. AI STORE | 우측 | 구매·상호작용 | 진열장, 냉장고, 계산대, 매점 NPC |
| G. 라운지 | 우측 하단 | 휴식·대화 | 소파, 테이블, 식물, 러그 |
| H. 계단 | 우측 상단 | 층 이동 | 계단, 난간, 층 안내 사인 |

## 5. Tiled 레이어 순서

같은 오브젝트가 겹쳐 보일 때의 순서를 고정한다.

1. `ground` — 로비·카페·매점·실외·물 바닥
2. `structure` — 벽, 유리벽, 문, 엘리베이터, 계단
3. `objects_lower` — 카운터, 진열대, 소파, 테이블, 화단 하단
4. `collision` — 이동 불가 영역(게임 화면에는 숨김)
5. `characters` — 플레이어와 NPC
6. `objects_upper` — 나무 수관, 간판 상단, 전경 식물
7. `interaction` — F 키/클릭 상호작용 지점(게임 화면에는 숨김)
8. `effects` — 분수 물줄기, 수면, 조명 등

## 6. 에셋 제작 규칙

### 공통 기준

- 투명 PNG, 32px 그리드에 맞춘 크기, 발 위치는 타일 하단 중앙에 맞춘다.
- 작은 화분은 1×1, 테이블은 2×2, 카운터·진열대는 최소 4×2, 나무는 최소 5×5 타일을 기준으로 한다.
- 벽·유리벽·난간은 반복 가능한 조각과 모서리 조각을 분리한다.
- 한 장의 완성 배경을 잘라 붙이지 않는다. 각 시설은 독립 에셋으로 만들어 재배치 가능해야 한다.

### 제작 순서

1. 바닥 타일 세트: 로비, 카페 목재, 매점 타일, 라운지, 입구, 보도, 물, 화단 경계
2. 구조물 세트: 외벽·내벽·유리벽·문·엘리베이터·계단·난간
3. 대형 랜드마크: 중앙 나무 화단, 리셉션, 카페 카운터, 매점 진열 벽
4. 가구·장비: 테이블, 의자, 소파, 냉장고, 커피머신, POS
5. 조경·브랜딩: 연못, 분수, 식물, 로고, 층 안내판, 매장 간판
6. NPC와 효과: 리셉션·카페·매점 NPC, 분수·조명 애니메이션

## 7. 동선과 충돌 기준

- 메인 동선은 최소 3타일, 보조 동선은 최소 2타일 폭으로 둔다.
- NPC와 플레이어가 스칠 공간으로 모든 가구 주변에 최소 1타일을 확보한다.
- 충돌: 벽, 유리벽, 카운터, 진열대, 소파, 화단의 하단, 연못·분수, 계단 난간.
- 통과 가능: 나무의 상단 잎, 벽 상단 장식처럼 시각적 레이어만 차지하는 부분.

## 8. 구현 단계와 완료 기준

| 단계 | 작업 | 완료 확인 |
| --- | --- | --- |
| 0 | Tiled 48×32 빈 지도와 8개 구역 가이드 배치 | 레퍼런스와 구역·동선이 맞는 정적 이미지 검토 |
| 1 | 바닥 타일과 외부 입구 완성 | 1536×1024 미리보기에서 바닥 경계·전환 확인 |
| 2 | 벽·유리·엘리베이터·계단 배치 | 구조물이 구역을 침범하지 않는지 확인 |
| 3 | 로비·카페·스토어·라운지 대형 에셋 배치 | 레퍼런스와 실루엣·좌우 균형 비교 |
| 4 | 소품·식물·브랜딩·NPC 배치 | 확대 화면에서 잘림·겹침·발 위치 확인 |
| 5 | Flame 가져오기, 이동·카메라·충돌 | 직접 실행해 이동 가능 영역과 충돌 확인 |
| 6 | 시설 상호작용 | 리셉션·엘리베이터·카페·매점·라운지 동작 확인 |

각 단계는 스크린샷을 직접 확인한 뒤에만 다음 단계로 진행한다. 디자인 승인 전에는 다음 단계의 게임 기능을 추가하지 않는다.

## 9. 첫 작업: 지도 설계 승인본

다음 작업은 에셋 제작이 아니라, 48×32 그리드 위에 8개 구역·주 동선·출입구·엘리베이터·중앙 나무·카페·매점의 자리를 표시한 **무채색 Tiled 레이아웃 초안**을 만드는 것이다. 이 초안을 사용자에게 먼저 보여 주고, 구역 크기와 위치가 승인된 뒤 바닥 에셋부터 제작한다.
