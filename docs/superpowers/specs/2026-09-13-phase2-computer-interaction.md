# Phase 2 컴퓨터 상호작용 설계

## 목표

플레이어가 오피스의 컴퓨터에 가까이 가서 `E` 키로 사용할 수 있고, 게임 위에 AI 직원 컴퓨터 팝업을 열고 닫을 수 있게 한다.

## 사용자 흐름

1. 플레이어가 컴퓨터의 상호작용 거리 안으로 이동한다.
2. 화면에 `[E] 컴퓨터 사용` 안내가 표시된다.
3. `E` 키를 누르면 게임 입력을 멈추고 컴퓨터 팝업을 연다.
4. 팝업에 `개발 AI`, `대기 중`, `업무 지시`, `대화하기`, `작업 확인`을 표시한다.
5. 닫기 버튼 또는 ESC 키를 누르면 팝업을 닫고 게임 입력으로 돌아간다.

## 범위

- 기존 오피스 맵의 컴퓨터 오브젝트 한 대에 상호작용 영역 연결
- 접근 여부와 팝업 열림 여부를 관리하는 게임 상태
- Flame 게임 화면 위에 표시되는 Flutter 오버레이 팝업
- 키보드 접근·열기·닫기 동작과 화면 표시 테스트
- Chrome 시각 QA

## 제외 범위

버튼의 실제 업무 실행, AI API, 채팅, Supabase 저장, 멀티플레이, NPC 이동은 포함하지 않는다.

## 완료 기준

Chrome에서 컴퓨터 가까이 이동했을 때 안내가 보이고, E로 팝업을 열며 ESC·닫기 버튼으로 닫힌 뒤 다시 캐릭터를 이동할 수 있다.
