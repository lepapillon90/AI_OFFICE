# 아이소메트릭 1층 로비 전환 설계

## 목표

현재의 탑다운 1층 로비를, 제공된 레퍼런스와 같은 2.5D 아이소메트릭 디오라마 공간으로 전환한다. 플레이어, NPC, 컴퓨터 상호작용, 충돌, 엘리베이터 층 전환은 유지한다. 2~4층은 이번 작업 범위에서 변경하지 않는다.

## 범위

- 1층(`Floor.lobby`)만 새 렌더링과 좌표 체계로 전환한다.
- 입체 사선 바닥, 벽, 가구, 전경 오브젝트를 레이어로 표시한다.
- 플레이어와 NPC는 화면상 Y 위치에 따라 가구의 앞/뒤로 자연스럽게 정렬한다.
- 현재의 키보드 이동, 충돌, 컴퓨터 접근, 엘리베이터 이동을 계속 지원한다.
- 좁은 화면에서는 카메라 확대 비율을 높여 조작 가능한 범위를 유지한다.

## 제외 범위

- 2~4층의 시점 변경
- 완전한 수학적 아이소메트릭 타일 엔진 및 대각선 전용 이동 규칙
- 멀티플레이 동기화 방식 변경
- 로그인, Supabase, 직원 데이터 모델 변경

## 구조

`OfficeGame`은 현재처럼 층 선택, 플레이어, NPC, 엘리베이터, 오버레이를 소유한다. 1층일 때만 `IsoLobbyMap`과 `IsoFloorLayout`을 선택하며, 다른 층은 기존 `FloorMapComponent`를 계속 사용한다.

```text
OfficeGame
├── IsoLobbyMap (1층 표현)
│   ├── background: 하늘·건물 외곽
│   ├── ground: 아이소메트릭 바닥
│   ├── midground: 벽·카페·리셉션·가구
│   └── foreground: 식물·난간·전경 장식
├── IsoFloorLayout (1층 충돌·상호작용 좌표)
├── OfficePlayer / NpcComponent (Y 기반 깊이 정렬)
└── ElevatorInteraction / ComputerInteraction
```

## 좌표와 깊이

월드 좌표는 기존처럼 2D `Vector2` 화면 좌표를 사용한다. 이번 1층은 완전한 수학적 타일 투영이 아닌 **아이소메트릭 아트가 적용된 2.5D 디오라마**이므로, 플레이어·충돌·카메라 좌표를 별도 투영하지 않는다. 게임 규칙과 충돌은 현재 좌표에 남기므로 기존 입력과 상호작용 코드에 영향을 주지 않는다.

각 렌더 요소의 깊이는 화면 발 위치의 Y 값으로 계산한다. 작은 Y는 뒤, 큰 Y는 앞에 그린다. 플레이어와 NPC는 매 프레임 이 값을 갱신하여 테이블·소파 등의 중간 레이어와 자연스럽게 섞인다.

## 맵 데이터

1층 맵은 다음 데이터로 분리한다.

- 바닥 타일 및 배경 배치
- 정적 가구와 장식의 월드 좌표·크기·깊이 기준점
- 통과할 수 없는 충돌 사각형
- 컴퓨터, 카페, 안내 데스크, 엘리베이터의 상호작용 기준점

충돌 사각형과 상호작용 지점은 이미지 픽셀에 직접 묶지 않는다. 별도 `IsoFloorLayout`에 정의해 아트 에셋 변경 시 게임 규칙을 안전하게 수정할 수 있게 한다.

## 카메라와 반응형 동작

카메라는 플레이어를 추적하고 1층 월드 경계 안에 머문다. 넓은 브라우저에서는 로비 전체의 입체감을 보여 주고, 좁은 화면에서는 줌을 높여 플레이어와 가까운 상호작용 물체를 읽기 쉽게 한다. 레이아웃 변화는 카메라 줌만 조정하며 게임 규칙을 바꾸지 않는다.

## 오류 처리

- 누락된 아이소메트릭 에셋은 조용히 빈 화면으로 처리하지 않고, 개발 환경에서 명확한 오류를 발생시킨다.
- 전환 데이터에 없는 상호작용 물체는 등록하지 않는다.
- 충돌 데이터가 잘못되어 플레이어가 맵 밖으로 갈 수 있는 경우, 기존 월드 경계 검사를 최종 방어선으로 유지한다.

## 검증

- 단위 테스트: 1층 선택 시 아이소메트릭 레이아웃과 기존 층 전환이 올바르게 선택되는지 확인한다.
- 단위 테스트: 플레이어가 새 1층 충돌 영역을 통과하지 못하고 엘리베이터 근처로 이동하는지 확인한다.
- 단위 테스트: 깊이 계산이 발 위치 Y 값에 따라 정렬 키를 만드는지 확인한다.
- 수동 QA: 웹에서 1층을 열어 이동, 가구 앞뒤 가림, 컴퓨터 팝업, 엘리베이터를 직접 확인하고 스크린샷을 읽는다.
- 회귀 QA: 2~4층 전환, 기존 컴퓨터 상호작용, 기존 NPC 표시를 확인한다.

## 완료 기준

1층이 2.5D 아이소메트릭 디오라마로 보이고, 플레이어와 NPC가 사선 공간을 자연스럽게 이동하며, 충돌·컴퓨터 상호작용·엘리베이터가 기존대로 동작한다. 2~4층은 변경 없이 계속 표시된다.
