# 1층 바닥 타일 세트

원본 타일 시트에서 직접 분리한 86×86 PNG 에셋입니다. 각 바닥 유형은 같은 파일 구성을 가집니다.

- `base`: 기본 타일
- `variation_a`, `variation_b`: 반복 패턴을 줄이는 변형
- `edge`, `inner_corner`, `outer_corner`: 벽과 공간 외곽용 타일
- `transition`: 서로 다른 바닥 재질을 잇는 타일
- `accent`: 포인트 타일
- `border_trim`: 경계 마감 타일
- `special`: 구역 전용 타일

포함된 바닥 구역은 `main_lobby`, `reception_lobby`, `cafe`, `store`, `lounge`, `elevator_front`, `stair_landing`, `indoor_entrance`, `outdoor_plaza`, `pond_walkway`, `shallow_water`, `planter_edge`입니다.
